# Guías de Portal Andino V2

Guía de instalación y guía de uso de [Portal Andino V2](https://github.com/datosgobar/portal-andino-v2), pensadas para que organismos nacionales, provinciales y municipales pongan en marcha su propia instancia. El sitio está hecho con [Astro](https://astro.build/) y [Starlight](https://starlight.astro.build/), y el contenido está escrito en Markdown.

## Levantarlo en local

```bash
npm install
npm run dev
```

El sitio queda en http://localhost:4321/guias-andino/ y se recarga solo al editar. Hace falta Node 22 o superior.
